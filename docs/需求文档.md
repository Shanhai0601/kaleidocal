# KaleidoCal 需求文档

## 1. 项目背景与动机

历法是文明对时间的想象。同一个太阳、同一个月亮，不同文明却发展出截然不同的计时方式：中国农历用「定气定朔」调和日月，玛雅人用多套并行历法记录神与人的节律，法国大革命曾试图用十进制历法改造时间本身。

这些历法大多已成为「冷知识」——它们精确、精巧、有历史厚度，却很少被现代人触及。本项目希望做一个**有趣、可把玩、可交叉验证**的冷门历法换算工具，让用户输入任意一个公历日期，就能看到它在多套历法下的样子，体会「时间坐标」的相对性。

## 2. 目标用户

- 对历史、天文、文化感兴趣的普通用户；
- 需要快速查询农历 / 干支 / 玛雅历 / 共和历的写作者、内容创作者；
- 学习历法换算算法原理的开发者（代码即文档）。

## 3. 功能需求

### 3.1 核心换算（P0）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 公历 ↔ 儒略日 | 支持格里历 / 儒略历，1582 改革自动切换 |
| F2 | 公历 → 农历 | 输出年月日、闰月、干支年、生肖 |
| F3 | 公历 → 干支 | 纪年、纪日、纪时（五鼠遁） |
| F4 | 公历 → 玛雅历 | 长纪历、卓尔金历、哈布历、历法轮回 |
| F5 | 公历 → 法国共和历 | 年月日、补日、中文月名 |
| F6 | 某公历年农历全览 | 春节日期、闰月、各月天数 |

### 3.2 综合排盘（P0）

- 输入一个公历日期，一次性展示其在公历、儒略日、农历、干支、玛雅历、共和历下的全部坐标。

### 3.3 交互方式（P0）

- 命令行（CLI），无外部依赖，`pip install -e .` 即可使用；
- 无参数默认展示「今天」的综合排盘。

## 4. 非功能需求

- **正确性**：每个模块都要有独立的历史锚点对拍（玛雅 2012-12-21 = 13.0.0.0.0、2019-01-27 = 甲子日、春节日期、热月政变日期等），测试必须全绿。
- **纯算法、零数据表**：不内置万年历，所有日期由天文公式实时计算，规避查表边界错误，也保证跨大范围年份可用。
- **可移植**：Python 3.9+，仅用标准库，无第三方运行时依赖。
- **可维护**：模块按历法划分，单一职责；儒略日作为统一中间层，避免 O(N²) 的两两转换。
- **可扩展**：新增一种历法，只需实现「该历法 ↔ 儒略日」两个函数即可接入综合排盘。

## 5. 范围边界（非目标）

- 不做 GUI / Web 界面（当前版本仅 CLI）；
- 不处理时区多选（农历默认北京时间，玛雅/共和历按儒略日连续计）；
- 不追求天文历书级秒级精度（±1 分钟已足够确定日期归属）；
- 不做节日、黄历、星象等延伸功能。

## 6. 验收标准

- `python -m pytest -q` 全绿（32 个用例）；
- 下列锚点输出与权威历表一致：
  - 2012-12-21 → 玛雅长纪历 13.0.0.0.0，历法轮回 4 Ahau / 3 Kankin；
  - 2019-01-27 → 日柱「甲子」；
  - 1794-07-27 → 共和历 An 2 热月 9 日（热月政变）；
  - 2023/2024/2025 春节日期与闰月号正确（2023 闰二月、2025 闰六月）。
- `python -m kaleidocal`（无参数）不报错，正确输出「今天」的排盘。
